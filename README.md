# F1TENTH RL Agent
Graduate project for CS5180 - Reinforcement Learning and Sequential Decision Making, Spring 2026 Semester @ Northeastern University.
 
Implementing Soft Actor-Critic (SAC) for autonomous racing trajectory optimization.

## Usage
- `baseline.py`: Geometric "Follow the Gap" controller.
- `train.py`: RL training loop (PPO/SAC). 
- `wrapper.py`: Lidar observation processing.
